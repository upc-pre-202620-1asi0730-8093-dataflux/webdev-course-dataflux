# Lección 4: Introducción a CSS

*Duración objetivo:* 4 minutos  
*Archivo usado:* completed-examples/lesson-04/index.html y completed-examples/lesson-04/style.css  
*Editor utilizado:* CodePen  
*Objetivo:* Aplicar la sintaxis de CSS, usar selectores y clases para cambiar colores y fuentes.

## Guion para grabar

### — Apertura
*En pantalla:* Muestra de la página sin CSS y luego con CSS aplicado.

*Voz:*
> Qué tal. Hasta ahora la página es solo texto plano. Hoy veremos CSS, que es el lenguaje para cambiar colores, tamaños de letra y fondos.

### — Sintaxis de CSS
*Acción:* Escribir en el panel CSS la regla para body.

*Voz:*
> Una regla de CSS tiene tres partes: selector, propiedad y valor. Escribimos body, abrimos llaves y adentro ponemos background-color, dos puntos, el color que queramos y terminamos siempre con punto y coma.

### — Propiedades de texto
*Acción:* Cambiar color, font-family y font-size en h1 y p.

*Voz:*
> Para cambiar el color del texto usamos la propiedad color. Con font-family elegimos el tipo de letra, por ejemplo Arial. Con font-size cambiamos el tamaño en píxeles.

### — Clases CSS
*Acción:* Crear .caja-especial en CSS y usar class="caja-especial" en HTML.

*Voz:*
> Si queremos cambiar solo un elemento específico sin modificar los demás, usamos clases. En CSS escribimos un punto seguido del nombre de la clase. Luego en HTML agregamos el atributo class con ese mismo nombre.

### — Demostración en vivo
*Acción:* Modificar colores en tiempo real en CodePen.

*Voz:*
> Como ven en CodePen, los cambios se aplican automáticamente al panel derecho apenas editamos el código CSS.

### — Reto de la lección
*En pantalla:* "Pausa: Cambia el fondo de tu página y crea una clase para un título."

*Voz:*
> Pausa el video, cambia el color de fondo en tu código y crea una clase para darle un tamaño diferente a tu título.

### — Cierre
*Voz:*
> Con esto cubrimos las bases de CSS. En la lección 5 integraremos todo para crear un proyecto completo.
