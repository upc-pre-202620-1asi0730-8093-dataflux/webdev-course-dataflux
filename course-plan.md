# HTML and CSS Start: Basics

## 1. Resumen del curso
HTML and CSS Start es un curso introductorio de Java dirigido a estudiantes de 12 a 17 años sin experiencia previa.
El curso utiliza videojuegos como temática común y desarrolla progresivamente un registro orientado a objetos. Todos los ejemplos y actividades pueden ejecutarse desde un navegador mediante CodePen.

**Repositorio de código fuente:** [Abrir repositorio en GitHub](https://github.com/upc-pre-202620-1asi0730-8093-dataflux/webdev-course-dataflux)

## 2. Público objetivo

Estudiantes de secundaria de 12 a 17 años interesados en el desarrollo web.
No se asume experiencia previa con HTML ni con CSS.

## 3. Prerrequisitos

- Manejo básico de un navegador web.
- Conexión a Internet.
- Capacidad para copiar, modificar y ejecutar código.
- No se requiere un entorno de desarrollo local.

## 4. Objetivo general

- Desarrollar una página web utilizando etiquetas de encabezado, párrafo, listas, imágenes y darle estilo a un color y tamaño definido a los textos.

  

## 5. Objetivos de aprendizaje

Al finalizar el curso, el estudiante podrá:  

1. Reconocer la estructura básica de una página web. 

2. Crear encabezados y párrafos. 

3. Utilizar listas ordenadas y desordenadas. 

4. Insertar imágenes del internet. 

5. Crear enlaces que redirijan a páginas externas. 

6. Cerrar las etiquetas de un elemento de HTML cuando corresponda. 

7. Seleccionar elementos en CSS para modificar sus propiedades. 

8. Enlazar un archivo HTML con un archivo CSS.
