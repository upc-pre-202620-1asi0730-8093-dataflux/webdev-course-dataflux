## Descripción

El curso presenta los conceptos básicos de HTML y CSS mediante seis lecciones breves y progresivas.

Cada lección contiene:

- Un video explicativo.
- Un archivo inicial con actividades marcadas como `TODO`.
- Una solución completa disponible en el repositorio.
- Un reto breve para aplicar lo aprendido.
- Un resumen final.

Todas las actividades se realizan directamente desde el navegador. El estudiante no necesita descargar archivos, ni configurar un entorno de desarrollo.

## Resultado final

Al terminar el curso, el estudiante podrá construir una página web que:

- Muestre encabezados, párrafos. 
- Muestre enlaces que redirijan a sitios externos.
- Muestre imágenes
- Tenga color 

## Público objetivo

Estudiantes de 12 a 17 años interesados en aprender programación y que no necesitan contar con experiencia previa.

## Prerrequisitos

- Manejo básico de un navegador web.
- Conexión a Internet.
- Interés por aprender a desarrollar una página web. 

No se necesita instalar un entorno de desarrollo local.

## Duración

- Lecciones: 6.
- Duración total aproximada: 45 minutos.
- Duración por lección: entre 4 y 12 minutos.

## ¿Qué aprenderás?

- Estructura básica de una página web.
- Encabezados y párrafos.
- Listas ordenadas y desordenadas.
- Insertar imágenes.
- Insertar enlaces externos.
- Modificar el color, tamaño y fuente de los textos.
- Modificar el color del fondo. 
- Utilizar clases para seleccionar elementos en CSS.
- Enlazar un archivo HTML con un archivo CSS. 
- Recomendaciones para organizar tu código HTML.

## Cómo utilizar el curso

### 1. Ver el video

Abre el video correspondiente y sigue la explicación hasta llegar al reto práctico.

### 2. Abrir el starter

Entra en la carpeta de la lección correspondiente y abre:

```text
starter-files/lesson-XX
```

Copia el código inicial mostrado en GitHub.

### 3. Ejecutar en CodePen

1. Abre [CodePen](https://codepen.io/create)
2. Selecciona un proyecto en blanco.
3. Pega el contenido del archivo starter 
4. Completa las actividades marcadas con `TODO`.
5. Comprueba el resultado obtenido al visualizar el panel derecho. 

Todo el procedimiento se realiza desde el navegador. No es necesario descargar los archivos del repositorio.

### 4. Consultar la solución

Después de intentar el ejercicio, revisa:

```text
completed-examples/lesson-XX
```

Compara tu implementación con la solución completa. Se recomienda intentar resolver las actividades antes de consultar esta sección.
